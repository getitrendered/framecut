## Framecut icon and Text List controls

- Framecut uses its green three-stripe icon for the Windows executable, installer, and shortcuts. This update uses the full installer to replace the executable.
- Font pickers open and scroll more smoothly in Text List and the title Inspector. The title preview shows the selected font.
- Text List has separate controls for text color, outline color, outline width, and extrusion color. Set outline width to 0 to turn off the outline.
