## Projects, compositions and LED walls

- The Projects home lists saved edits and lets you open an existing project or create a new one. Existing edits appear automatically.
- Set exact canvas dimensions and double the width and height together. Main and each composition can follow the edit length or use a fixed duration.
- Create compositions on their own timelines and add them to Main from the Compositions drawer. Set In and Out with **I** and **O** to export a range.
- Simulate multiple LED walls in 3D using dimensions in feet. Assign footage or a timeline, position the video inside the wall, and draw and measure custom wall outlines.
- Select clips individually with **Ctrl-click** or select a range on a track with **Shift-click**. Right-click to make repeated copies on the original tracks.
- Rename layers, resize the layer-name column, and see locked and muted states at a glance.
- Use **Import** beside Tasks for video, images, audio, subtitles, LUTs and OBJ models. Preview audio directly from Footage.
- Remove items from Footage without disrupting existing edits. Restore items from the Removed footage folder.
