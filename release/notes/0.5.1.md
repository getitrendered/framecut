## GitHub updates in Framecut

- Framecut checks for new releases on launch and every 30 minutes while open. You can also check manually from **Updates**.
- The update dialog shows release notes before download. Framecut reports download progress and verifies the installer checksum.
- **Save and Restart** keeps the current project, installs the update in your Framecut folder, and reopens the same profile.
- This release fixes the Windows handoff from Framecut to the installer.

Open or install this build once to enable future updates. This private release feed uses your GitHub CLI login and requires repository access.
