## Project-specific imports

- New projects start with an empty Footage bin. Video, images, audio, generated media, and imported LUTs appear in the project where you added them.
- Main and its compositions share the same project imports. Footage pickers in Edit, Sound Design, and LED Wall use that project’s library.
- Existing timelines, folder assignments, and wall sources keep their media. When multiple older projects shared a library, media with no identifiable project appears under **Recovered imports**.
- Fixed plain-text script imports so every nonblank line is imported in full.
