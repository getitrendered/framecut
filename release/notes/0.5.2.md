## GitHub updates in Framecut

Framecut checks for new versions shortly after launch and every 30 minutes while open. You can also check from **Updates**. The app shows release notes before downloading, displays download progress, and verifies the installer checksum.

**Save and Restart** saves the current project, waits for Framecut to close, runs the verified installer, and reopens the same project profile. This release includes a native Windows update helper with a startup check so the editor closes only after the updater is ready.

Open or install this build once to receive future updates. This private release feed uses your GitHub CLI login and requires repository access.
