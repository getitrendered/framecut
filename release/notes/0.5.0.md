## Updates in Framecut

- Framecut checks the GitHub release feed shortly after launch and periodically while open. The Updates button also provides a manual check.
- A new-version dialog shows the release notes and lets you choose when to download the installer.
- Downloads report progress and pass a SHA-256 integrity check before installation.
- Save and Restart saves the project, closes Framecut, installs the update, and reopens the same project profile.

This is the first release with built-in updates. Open or install it once to enable the updater. The private update feed uses your GitHub CLI login and requires repository access. Framecut uses the FFmpeg already installed on your PC.
